How it works

The same traffic runs through a fixed timer and through the adaptive controller, simulated in SUMO.

  1. BrowserYou choose a scenario and controllers on this page and press Run.
  2. Flask APIThe server checks the request and creates a run record in the database.
  3. Simulation runnerThe server starts a separate process with the scenario's traffic volumes.
  4. SUMO via TraCIEvery simulated second, the controller reads the queues and decides when the light changes.
  5. Metrics savedWhen the hour ends, average wait and time loss are calculated and stored.
  6. Results shown hereThis page and the dashboard read the stored runs and display them.
