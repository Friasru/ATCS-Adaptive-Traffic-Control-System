Desktop Monitor

Checking... Monitoring REC

Vehicle and pedestrian counting runs in the ATCS Monitor desktop app on Windows. Start a camera or video there; this page shows what the app reports to the ATCS server and keeps every finished session.

Open Desktop Monitor

Opens the app installed on this computer (the one running this browser), not on the ATCS server. Your browser may ask whether to open an external program: choose Open. Nothing starts until you press Start in the app.

Desktop not connecting?

  • Nothing opened: the atcs-monitor:// launcher is not installed on this computer, or the browser prompt was dismissed or blocked. Install it on Windows with monitor\scripts\windows\install_uri_handler.ps1 (see monitor/docs/desktop_link.md, section 7), and allow the prompt or re-enable it in the browser's site settings.
  • The app opened but this page still waits: check the ATCS: ... label in the app's status bar. Run python -m app.desktop_link check in the Windows monitor folder, and make sure the ATCS server (Flask) is running.
  • Different computer: the button can only open an app on the computer showing this page. On another computer, start the desktop app there; its results still appear here.
