3D Simulator

Explore real SUMO traffic simulations in 3D using the ATCS Fixed, Queue-Based, and Wait-Time controllers.

This is an actual SUMO simulation: SUMO moves every car, the real ATCS controller changes the lights, and this page only draws what SUMO reports. The Simulator and Compare pages are different: they run a simplified model written for the browser.

It is a small local program that runs SUMO for this page. ATCS starts it by itself; to start it yourself, run this from the repository folder:

      
simulation3d/run.sh

      
This page connects by itself as soon as the service is up. Everything else in ATCS keeps working without it. Setup and troubleshooting: simulation3d/README.md.
