# Provenance of the code in `simulation3d/`

The state bridge (`atcs3d/`), the renderer (`web/`), the stored benchmark results and most of the tests are copies of the
standalone 3dATCS project, which stays untouched.

| Item | Value |
|---|---|
| Source repository | https://github.com/Friasru/3dATCS (local checkout `~/3dATCS`, branch `main`) |
| Source commit | `440410d6ce6788c7cac2f1569ba811712e92b675` |
| Copied from | the **working tree** of that checkout on 2026-10-30, which had uncommitted changes (the counter work described in its `docs/COUNTER_INVESTIGATION.md`) |
| Copied files that differ from that commit | `atcs3d/sim_worker.py`, `tests/helpers.py`, `web/css/app.css`, `web/js/ui.js`, `web/js/view.js` (modified); `tests/test_counters.py`, `tests/test_counters_web.py` (not yet committed there) |
| Copied by | `cp` (read access to 3dATCS only), then each file checked byte for byte with `cmp` |

So this copy is the validated working code, not commit `440410d` alone. Once the counter work is committed in 3dATCS, run
`cmp` on the files above against it.

## Copied verbatim

Every file listed in [SHA256SUMS](SHA256SUMS) is a byte-for-byte copy: `atcs3d/{__init__,benchmark,netmodel,scenarios,server,
session,sim_worker,worker_client}.py`, all of `web/` (including the vendored three.js and its licence),
`results/benchmark_*.json`, `pytest.ini` and the tests `conftest`, `helpers`, `browser_util`, `test_server`, `test_bridge`,
`test_counters`, `test_web`, `test_counters_web`. `tests/test_integration_source.py` fails if one of them changes.

## Adapted

| File | Change |
|---|---|
| `atcs3d/paths.py` | `ATCS_SOURCE` is this repository's `simulation/` instead of 3dATCS's private `atcs_source/` copy; `REPO_ROOT` added; output stays under `simulation3d/output/`, results under `simulation3d/results/` |
| `tests/independent_reference.py` | imports the controllers from `simulation/`; SUMO's tripinfo and summary files go next to its recording instead of into `simulation/` (`baseline.sumocfg` would otherwise write them there) |
| `tests/test_parity.py` | the reference run of `simulation/runner.py` (itself unmodified) writes to a temporary directory instead of `simulation/output/` |
| `tests/test_results.py` | compares the stored benchmark with this repository's `results/` instead of `~/ATCS-Adaptive-Traffic-Control-System` |

The standalone 3dATCS lets that reference script write `tripinfo_baseline.xml` and `summary_baseline.xml` into its own
`atcs_source/` copy. In this repository that would have put untracked files into `simulation/`, hence the change above;
`tests/test_zz_simulation_untouched.py` fails if a test run adds, removes or changes anything in `simulation/`.

## Not needed here

`atcs_source/` (3dATCS's copy of the ATCS simulation files, commit `83f909d`; its controllers, runner, metrics, network and
SUMO configuration are byte-identical to this repository's `simulation/`, and `simulation/` has not changed since that
commit), `tests/test_source_integrity.py` (replaced by `tests/test_integration_source.py`), `scripts/`, `docs/`, the
`perf_*.json` measurements (specific to the computer they were taken on), and generated output.

## The stored benchmark

`results/benchmark_*.json` were generated by 3dATCS on 2026-10-28 (SUMO 1.18.0, seed 23423) with controllers byte-identical
to the ones in `simulation/`. `atcs_source_commit` in them is `83f909d`, the ATCS commit those controllers come from.
`tests/test_results.py` checks them against `results/results.json` and the Wait-Time tuning sweep of this repository.
Regenerate with `simulation3d/run.sh benchmark --all` after any change to a controller.
